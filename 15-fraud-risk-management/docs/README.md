# Fraud Risk Management — Portfolio Case Study

## Overview

This portfolio case study builds an enterprise fraud risk framework covering prevention, detection, and response across all banking channels — incorporating the fraud triangle, control frameworks, red flag indicators, and forensic investigation protocols.

**Label:** Portfolio Case Study — Synthetic Scenario

---

## 1. Complete Customer Lifecycle

```
Threat Identification → Control Design → Implementation → Monitoring → Incident Response → Recovery → Lessons Learned
```

| Stage | AS-IS Experience | TO-BE Experience |
|-------|------------------|------------------|
| **Threat ID** | Annual risk assessment | Continuous threat intelligence |
| **Control Design** | Generic controls | Risk-based targeted controls |
| **Implementation** | Manual policy updates | Automated control deployment |
| **Monitoring** | End-of-month reports | Real-time KPI dashboards |
| **Incident Response** | Ad-hoc escalation | Structured playbooks |
| **Recovery** | Minimal recovery tracking | Forensic accounting + asset recovery |
| **Lessons** | Siloed learnings | Centralized fraud knowledge base |
