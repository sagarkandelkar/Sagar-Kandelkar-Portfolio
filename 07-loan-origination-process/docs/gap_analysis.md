# Loan Origination — Gap Analysis

## Current State (AS-IS)

### Pain Points

| # | Pain Point | Impact |
|---|-----------|--------|
| 1 | Branch-only application for high-value loans | Customer drop-off |
| 2 | Manual credit appraisal takes 3-5 days | Slow turnaround |
| 3 | Document resubmission cycles | Delayed disbursement |
| 4 | No real-time application visibility | Customer anxiety |
| 5 | Physical sanction letter and agreement execution | Operational cost |

### AS-IS Metrics

| Metric | Current | Target | Gap |
|--------|---------|--------|-----|
| Application-to-Disbursement | 10-15 days | <48 hours | Significant |
| STP Rate | 15% | >60% | 45% |
| Customer Satisfaction | 3.0/5 | >4.2/5 | 1.2 points |
| Cost per Loan | ₹15,000 | <₹5,000 | ₹10,000 |

## Future State (TO-BE)

### Vision
A fully digital, STP-enabled loan origination platform with instant eligibility, automated appraisal, digital sanction, and same-day disbursement.

## Recommendations

### Phase 1 (0-2 months): Digital Foundation
- Launch mobile app loan application
- Deploy eligibility calculator
- Implement document OCR

### Phase 2 (2-4 months): Automation
- Auto CIBIL fetch and risk scoring
- STP for Grade A profiles
- Digital sanction and e-sign

### Phase 3 (4-6 months): Intelligence
- ML-based default prediction
- Dynamic pricing engine
- Pre-approved loan offers

| Benefit | Impact |
|---------|--------|
| Turnaround Time | 80% reduction |
| Cost per Loan | 65% reduction |
| Customer Satisfaction | +1.2 NPS |
| STP Rate | +45 percentage points |
