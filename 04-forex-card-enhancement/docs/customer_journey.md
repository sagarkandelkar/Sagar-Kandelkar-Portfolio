# Forex Card Customer Journey Map

## AS-IS Journey (Current State)

| Stage | Touchpoint | Customer Action | Emotion | Pain Point | Severity |
|-------|-----------|-----------------|---------|-----------|----------|
| **Discovery** | Bank website | Searches for Forex card options | 😐 Neutral | No clear product comparison | Medium |
| **Discovery** | Branch visit | Asks about Forex card | 😐 Neutral | Staff lacks product knowledge | Medium |
| **Application** | Branch counter | Fills physical application form | 😤 Frustrated | Branch-only, long queues | **High** |
| **Application** | Document submission | Submits passport, PAN, address proof | 😤 Frustrated | Multiple photocopies needed | Medium |
| **KYC** | Branch appointment | Returns for in-person KYC | 😠 Annoyed | Second branch visit required | **High** |
| **KYC** | Document verification | Waits for manual verification | 😐 Neutral | No visibility into status | Medium |
| **Issuance** | Phone/branch inquiry | Calls to check card status | 😤 Frustrated | No tracking mechanism | **High** |
| **Issuance** | Branch collection | Collects physical card after 5-7 days | 😐 Neutral | Long wait time | Medium |
| **Activation** | Branch/phone | Requests card activation | 😠 Annoyed | Cannot self-activate | Medium |
| **Loading** | Branch visit | Submits load request with currency | 😤 Frustrated | Branch-only, rate unknown | **High** |
| **Loading** | Rate confirmation | Receives rate at counter | 😠 Annoyed | No rate transparency, hidden markup | **High** |
| **Travel** | POS transaction | Swipes card abroad | 😊 Happy | — | — |
| **Travel** | ATM withdrawal | Withdraws cash at foreign ATM | 😐 Neutral | Unsure of fees and rates | Medium |
| **Travel** | Balance check | Calls helpline for balance | 😤 Frustrated | No real-time balance visibility | **High** |
| **Travel** | Budget tracking | Maintains manual expense log | 😠 Annoyed | No spend categorization | Medium |
| **Reload** | Branch/phone | Requests additional load | 😤 Frustrated | Branch dependency continues | **High** |
| **Support** | Lost card | Visits branch to report loss | 😰 Stressed | Delayed blocking, no self-service | **High** |
| **Support** | Dispute | Submits dispute form at branch | 😠 Annoyed | Manual process, no tracking | Medium |
| **Closure** | Expiry/repatriation | Requests unused balance transfer | 😤 Frustrated | 15+ day process, branch visit | **High** |

## TO-BE Journey (Future State)

| Stage | Touchpoint | Customer Action | Emotion | Experience Enhancement |
|-------|-----------|-----------------|---------|----------------------|
| **Discovery** | Mobile app / Website | Compares Forex card features online | 😊 Happy | Rich product comparison, travel calculator |
| **Discovery** | Personalized offer | Receives pre-approved offer via app | 😄 Excited | AI-based travel intent detection |
| **Application** | Mobile app | Applies in 3 minutes with pre-filled data | 😊 Happy | Auto-fill from existing relationship |
| **Application** | Document upload | Snaps passport and PAN via camera | 😊 Happy | OCR auto-capture and validation |
| **KYC** | Video KYC | Completes KYC via 3-minute video call | 😊 Happy | Anytime, anywhere verification |
| **KYC** | Real-time status | Tracks application status in app | 😊 Happy | Live progress tracker with ETA |
| **Issuance** | Digital card | Receives virtual card instantly | 😄 Excited | Instant issuance, < 2 hours |
| **Issuance** | Physical card | Card delivered to home/office | 😊 Happy | Courier tracking integrated |
| **Activation** | Self-service | Taps activate in app | 😊 Happy | One-tap digital activation |
| **Loading** | Mobile app | Selects currency, sees live rate | 😊 Happy | Real-time rate with markup transparency |
| **Loading** | Rate lock | Locks favorable rate for 30 min | 😄 Excited | Rate protection feature |
| **Travel** | POS transaction | Swipes card, gets instant alert | 😊 Happy | Real-time transaction notification |
| **Travel** | ATM withdrawal | Sees exact INR equivalent in alert | 😊 Happy | Transparent fee breakdown |
| **Travel** | Balance check | Opens app, sees all wallet balances | 😊 Happy | Multi-currency dashboard |
| **Travel** | Budget tracking | Views auto-categorized spends | 😊 Happy | Hotel, food, shopping, ATM buckets |
| **Travel** | Budget alert | Receives alert at 80% of set limit | 😊 Happy | Proactive limit management |
| **Reload** | Mobile app | Adds funds in seconds | 😊 Happy | One-tap reload, saved beneficiaries |
| **Support** | Self-service | Temporarily blocks card in app | 😌 Relieved | Instant block/unblock control |
| **Support** | Lost card | Reports loss, requests instant replacement | 😌 Relieved | Digital card active immediately |
| **Support** | Dispute | Raises dispute with photo evidence | 😊 Happy | In-app dispute with tracking |
| **Closure** | Repatriation | One-click balance transfer to savings | 😊 Happy | < 3 days to account |
| **Closure** | Expiry reminder | Receives proactive repatriation reminder | 😊 Happy | Never forgets unused balance |

| Card Issuance | 5-7 days | < 2 hours | **99% faster** |
| Load Process | Branch visit + waiting | 30 seconds in app | **Instant** |
| Balance Visibility | Call helpline | Real-time app | **Always available** |
| Repatriation Time | 15 days | < 3 days | **80% faster** |
| Customer Touchpoints | 12+ branch visits | 0 branch visits | **Fully digital** |
| NPS Score | 32 | 65+ | **+33 points** |
