---

## What is RACI?

| Letter | Meaning | Definition |
|--------|---------|------------|
| **R** | Responsible | Does the work |
| **A** | Accountable | Ultimately answerable (only ONE per task) |
| **C** | Consulted | Provides input before decision |
| **I** | Informed | Kept updated after decision |

## Key Accountability Notes

| Task | Single Accountable | Why |
|------|-------------------|-----|
| Product Vision | PM | Final call on what gets built |
| Requirements | BA | BA owns the "what" not the "how" |
| UX Design | UX | Design decisions are UX-led |
| Technical Delivery | IT | IT owns feasibility and delivery |
| Compliance | CO | Regulatory sign-off is mandatory |
| Operations Readiness | OM | Branch and support must be ready |
| Go-to-Market | ML | Marketing owns customer communication |
| Quality | QA | QA gates every release |
