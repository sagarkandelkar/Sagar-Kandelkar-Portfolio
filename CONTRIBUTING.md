# Contributing to Sagar Kandelkar — BFSI Portfolio

Thank you for your interest in contributing! This repository is a professional portfolio showcasing BFSI case studies and business analysis work.

## How to Contribute

### Reporting Issues
- Use [GitHub Issues](../../issues) to report bugs or suggest improvements
- Provide clear descriptions, steps to reproduce, and expected vs actual behavior
- Include screenshots where relevant

### Suggesting Enhancements
- Open an issue with the label `enhancement`
- Describe the value it adds to portfolio visitors or repo maintainability

### Content Contributions
- Case study data must be **synthetic** — no real PII or proprietary banking data
- Follow the existing folder structure: `docs/`, `data/`, `sql/`, `dashboard/`
- Ensure all Markdown files use proper formatting and frontmatter where applicable

### Code Contributions (Portfolio Website)
- The site is built with **React 19 + Vite**
- Run `npm run dev` inside `portfolio-website/` for local development
- Run `npm run lint` before committing
- Ensure responsive design works down to 320px width

## Style Guidelines

- **Markdown**: Use ATX-style headings (`#`), fenced code blocks with language tags
- **SQL**: Uppercase keywords (`SELECT`, `WHERE`), lowercase identifiers
- **Commit Messages**: Use clear, imperative mood (`Add fraud detection schema`, not `Added...`)
