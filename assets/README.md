# Repository Assets

This folder contains visual assets for the repository.

## Social Preview Image

**To make this repository stand out when shared on LinkedIn, Twitter, or other platforms:**

1. Create a 1280×640px image (e.g., in Canva or Figma)
2. Include:
   - Your name / brand
   - "BFSI Business Analysis Portfolio"
   - A visual hook (e.g., dashboard mockup, process flow snippet)
   - Consistent color scheme matching your portfolio site
3. Save it here as `social-preview.png`
4. Go to **GitHub Repo → Settings → Social preview**
5. Upload the image

> **Tip:** You can also use `social-preview.png` as the Open Graph image in your portfolio website's `<meta property="og:image">` tag.
