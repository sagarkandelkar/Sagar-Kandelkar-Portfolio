# Bank Account Lifecycle — Portfolio Case Study

## Overview

This portfolio case study maps the complete bank account lifecycle — from prospecting and onboarding through activation, usage, dormancy prevention, and structured closure — to maximize customer lifetime value while minimizing dormancy.

**Label:** Portfolio Case Study — Synthetic Scenario

---

## 1. Complete Customer Lifecycle

```
Prospecting → Onboarding → Activation → Usage → Up-sell → Retention → Dormancy → Revival → Closure
```

| Stage | AS-IS Experience | TO-BE Experience |
|-------|------------------|------------------|
| **Prospecting** | Cold calling | AI-based lookalike targeting |
| **Onboarding** | Paper-based KYC | Digital KYC with instant activation |
| **Activation** | 30% never activate | Proactive nudges + activation rewards |
| **Usage** | Basic transactions | Cross-sell savings, FD, insurance |
| **Up-sell** | Product-pushing | Needs-based recommendation engine |
| **Retention** | Reactive churn calls | Predictive intervention before churn |
| **Dormancy** | Detected after 12 months | Early warning at 3 months inactivity |
| **Revival** | Branch visit required | Digital re-engagement campaigns |
| **Closure** | Manual process | One-click digital closure with survey |

---

## 2. Transformation Impact — AS-IS vs TO-BE

| Metric | Before (AS-IS) | After (TO-BE) | Improvement |
|--------|---------------|---------------|-------------|
| **Dormancy Rate** | 22% | 9% | **59% reduction** |
| **Products per Customer** | 2.1 | 3.8 | **+1.7 products** |
| **Lifecycle Revenue** | ₹12K | ₹21K | **+75%** |
| **Activation Rate** | 70% | 92% | **+22 points** |
| **Cross-sell Success** | 12% | 34% | **2.8x better** |
| **Customer Lifetime** | 4.2 years | 7.8 years | **+86%** |
