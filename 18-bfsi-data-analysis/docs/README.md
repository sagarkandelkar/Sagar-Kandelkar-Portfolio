# BFSI Data Analysis — Portfolio Case Study

## Overview

This portfolio case study demonstrates data-driven business analysis using SQL, Python, and statistical methods — transforming raw banking data into actionable insights for decision-makers.

**Label:** Portfolio Case Study — Synthetic Scenario

---

## 1. Complete Customer Lifecycle

```
Requirement → Data Sourcing → Cleaning → Exploration → Modeling → Visualization → Insight Delivery → Action
```

| Stage | AS-IS Experience | TO-BE Experience |
|-------|------------------|------------------|
| **Requirement** | Vague business asks | Structured problem framing |
| **Sourcing** | Siloed data requests | Unified data catalog + self-service |
| **Cleaning** | Manual Excel work | Automated pipelines with validation |
| **Exploration** | Ad-hoc SQL queries | Systematic EDA with documentation |
| **Modeling** | Spreadsheet formulas | Python/R statistical models |
| **Visualization** | Static charts | Interactive dashboards with drill-down |
| **Delivery** | Email attachments | Embedded analytics in workflows |
| **Action** | Insight without follow-up | Closed-loop action tracking |

---

## 2. Transformation Impact — AS-IS vs TO-BE

| Metric | Before (AS-IS) | After (TO-BE) | Improvement |
|--------|---------------|---------------|-------------|
| **Analysis Turnaround** | 2 weeks | 2 days | **86% faster** |
| **Insight Accuracy** | Manual guess | Data-backed | **Evidence-based** |
| **Decision Speed** | Monthly reviews | Real-time alerts | **Continuous** |
| **Data Coverage** | 15% of available data | 85% of available data | **5.7x more** |
| **Self-Service Adoption** | 5% of business users | 45% of business users | **9x growth** |
| **Repeat Analysis** | Same questions weekly | Reusable models + auto-refresh | **Zero repeat** |
