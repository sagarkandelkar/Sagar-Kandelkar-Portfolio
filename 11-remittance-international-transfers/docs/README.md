# Remittance & International Transfers — Portfolio Case Study

## Overview

This portfolio case study analyzes international money transfer flows — covering SWIFT, correspondent banking, and emerging fintech alternatives — to optimize FX conversion, reduce transfer time, and improve beneficiary experience.

**Label:** Portfolio Case Study — Synthetic Scenario

---

## 1. Complete Customer Lifecycle

```
Initiation → Compliance Check → FX Conversion → Intermediary Routing → Beneficiary Credit → Confirmation → Reconciliation
```

| Stage | AS-IS Experience | TO-BE Experience |
|-------|------------------|------------------|
| **Initiation** | Branch form + high fees | Mobile app with live FX calculator |
| **Compliance** | Manual document review | Automated AML screening |
| **FX Conversion** | Hidden markup + 3.5% margin | Transparent rate with 1.2% margin |
| **Routing** | Opague correspondent chain | SWIFT gpi with full visibility |
| **Beneficiary Credit** | 3-5 days uncertainty | Same-day or next-day guarantee |
| **Confirmation** | No tracking | Real-time status updates |
| **Reconciliation** | Manual monthly | Auto-reconciliation with partner banks |

---

## 2. Transformation Impact — AS-IS vs TO-BE

| Metric | Before (AS-IS) | After (TO-BE) | Improvement |
|--------|---------------|---------------|-------------|
| **Transfer Time** | 3–5 days | < 24 hours | **90% faster** |
| **FX Margin** | 3.5% | 1.2% | **66% cheaper** |
| **Tracking Visibility** | Opaque | Real-time | **End-to-end** |
| **Customer Satisfaction** | 2.9 / 5 | 4.3 / 5 | **+1.4 points** |
| **Cost per Transfer** | ₹2,800 | ₹850 | **70% lower** |
| **Failure Rate** | 8% | 1.5% | **81% reduction** |
