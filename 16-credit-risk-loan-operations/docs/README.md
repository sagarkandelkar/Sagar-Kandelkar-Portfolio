# Credit Risk & Loan Operations — Portfolio Case Study

## Overview

This portfolio case study covers the credit risk lifecycle from application scoring to NPA recovery — incorporating PD/LGD modeling, Basel compliance, portfolio monitoring, early warning systems, and recovery strategies.

**Label:** Portfolio Case Study — Synthetic Scenario

---

## 1. Complete Customer Lifecycle

```
Application → Bureau Check → Income Verification → Collateral Assessment → Credit Scoring → Approval → Monitoring → NPA Management
```

| Stage | AS-IS Experience | TO-BE Experience |
|-------|------------------|------------------|
| **Application** | Paper-based with manual entry | Digital with auto-fill and validation |
| **Bureau Check** | Single CIBIL report | Multi-bureau + alternative data |
| **Income Verification** | Physical salary slips | API-based bank statement analysis |
| **Collateral** | Manual property valuation | Digital valuation with drone imagery |
| **Credit Scoring** | Static scorecard | ML model with 200+ features |
| **Approval** | Credit committee (7 days) | Risk-based auto-decision |
| **Monitoring** | Monthly batch review | Real-time portfolio monitoring |
| **NPA Management** | Legal recovery only | Early warning + restructuring + recovery |
