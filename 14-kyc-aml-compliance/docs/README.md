# KYC / AML Compliance Process — Portfolio Case Study

## Overview

This portfolio case study designs a comprehensive anti-money laundering and KYC compliance framework — covering perpetual KYC, AI-driven screening, risk-based approach, and regulatory reporting — to meet RBI and FATF standards.

**Label:** Portfolio Case Study — Synthetic Scenario

---

## 1. Complete Customer Lifecycle

```
Customer Identification → Verification → Risk Rating → Ongoing Monitoring → Screening → Investigation → Reporting
```

| Stage | AS-IS Experience | TO-BE Experience |
|-------|------------------|------------------|
| **Identification** | Paper documents | Digital identity verification |
| **Verification** | Manual document check | AI OCR + biometric verification |
| **Risk Rating** | Annual static assessment | Continuous dynamic risk scoring |
| **Monitoring** | End-of-year batch review | Real-time transaction monitoring |
| **Screening** | Manual sanctions list check | Automated PEP/sanctions screening |
| **Investigation** | Spreadsheet case management | Integrated alert investigation |
| **Reporting** | Manual SAR preparation | Auto-generated regulatory reports |

---

## 2. Transformation Impact — AS-IS vs TO-BE

| Metric | Before (AS-IS) | After (TO-BE) | Improvement |
|--------|---------------|---------------|-------------|
| **KYC Refresh Cycle** | 3 years | Continuous | **Perpetual** |
| **False Alerts** | 85% | 30% | **65% reduction** |
| **SAR Filing Time** | 5 days | 4 hours | **95% faster** |
| **Compliance Cost** | ₹8 Cr | ₹3.5 Cr | **56% lower** |
| **Regulatory Findings** | 12 per year | 1 per year | **92% reduction** |
| **Customer Friction** | High (frequent re-KYC) | Low (invisible monitoring) | **Seamless** |

---

## 3. Digital Enhancement Themes

| Theme | Description | Impact |
|-------|-------------|--------|
| **Perpetual KYC** | Continuous monitoring vs periodic refresh | Always compliant |
| **AI Screening** | ML models for PEP/sanctions detection | Accuracy +40% |
| **Risk-Based Approach** | Customer segmentation by AML risk | Right intensity for right customer |
| **RegTech Integration** | Automated regulatory reporting | Zero manual SAR drafting |
| **SAR Filing** | Auto-populated suspicious activity reports | Filing time -95% |
