# BFSI Customer Onboarding & KYC — Portfolio Case Study

## Overview

This portfolio case study analyzes the complete customer onboarding journey — from initial discovery and digital application through KYC verification, AML screening, and account activation — to identify digital transformation opportunities that reduce friction while maintaining regulatory compliance.

**Label:** Portfolio Case Study — Synthetic Scenario

---

## 1. Complete Customer Lifecycle

```
Discovery → Application → Document Upload → KYC Verification → AML Screening → Account Opening → Welcome Kit
```

| Stage | Touchpoint | AS-IS Experience | TO-BE Experience |
|-------|-----------|------------------|------------------|
| **Discovery** | Bank website / Branch | Customer browses products with limited comparison | Interactive product comparison with eligibility calculator |
| **Application** | Branch / Web / Mobile | Paper form, 45 min at branch | 3-minute mobile app with auto-fill |
| **Document Upload** | Branch photocopies | Multiple photocopies, manual handling | Camera upload with OCR auto-validation |
| **KYC Verification** | Branch visit / In-person | Second branch visit for KYC | Video KYC completed in 3 minutes |
| **AML Screening** | Manual batch processing | Delayed screening, overnight batch | Real-time screening with instant results |
| **Account Opening** | Back-office processing | 5-7 days manual processing | Automated account setup in minutes |
| **Welcome Kit** | Physical mail | 7-10 days postal delivery | Digital welcome kit + optional physical |

---

## 2. Transformation Impact — AS-IS vs TO-BE

| Metric | Before (AS-IS) | After (TO-BE) | Improvement |
|--------|---------------|---------------|-------------|
| **Account Opening Time** | 5 days | 10 minutes | **99% faster** |
| **KYC Completion** | Branch visit required | Fully digital Video KYC | **Fully remote** |
| **Application Drop-off Rate** | 35% | 12% | **65% reduction** |
| **Customer Satisfaction** | 3.1 / 5 | 4.6 / 5 | **+1.5 points** |
| **Operational Cost** | ₹2,800 per onboarding | ₹450 per onboarding | **84% lower** |
| **Compliance Accuracy** | 88% | 99.5% | **+11.5 points** |
| **First Transaction Time** | Day 8 | Day 0 (instant) | **Immediate activation** |

---

## 3. Digital Enhancement Themes

| Theme | Description | Impact |
|-------|-------------|--------|
| **Digital KYC** | Video KYC, Aadhaar OTP, e-KYC integration | Eliminates branch dependency |
| **OCR Automation** | Auto-extract data from PAN, passport, address proof | Reduces manual entry errors |
| **AML Compliance** | Real-time sanctions screening, PEP checks, risk scoring | Instant compliance decisions |
| **Frictionless UX** | Single-page application, progress save, instant feedback | Reduces drop-off by 65% |
| **Digital Welcome Kit** | Net banking credentials via SMS/email, virtual debit card | Instant product usage |
